# runs/

Committed result data. Which claim rests on which file is recorded in
[`evidence/claim_ledger.md`](../evidence/claim_ledger.md), and every file's hash and provenance in
[`evidence/manifest.json`](../evidence/manifest.json). Look there rather than here; this page only
says what each directory is for.

| Directory | Contents |
|---|---|
| `agent/` | Model runs from the custom harness: retrieval and election suites, the authoring suites, and the `synth_*` delivery-timing arms |
| `pilot/` | Pilot and case-series runs, including the navigation-v2 reread and checker-gate cohorts |
| `protocol/` | Mechanical validation: task-set gates, frozen selections, and the AST-resolver-versus-Pyrefly agreement check |
| `confirmation/` | The pre-registered substitution confirmation, run once on a reserved split |
| `readreq/` | The read-required boundary grid |
| `realbench/` | Real-repository scanning and the dispatch ladder; `repos/` and `eval/` are untracked |
| `sft/` | Trained LoRA adapters. Untracked: regenerable from the `run_*.sh` drivers |
| `logs/` | Stdout from long runs. Untracked |

Nothing here is regenerated by `scripts/analysis/reproduce_all.py`; it reads these files and checks
them. Regenerating any of it needs a GPU or API credentials, and the drivers are listed in the
[top-level README](../README.md).
